# ECG-Myocardiac
Developed a multi-task 1D convolutional neural network (1D CNN) with a shared backbone to simultaneously perform five-class arrhythmia classification using the MIT-BIH dataset and binary myocardial infarction (MI) detection using the PTB dataset. The model integrates four ECG signal channels to learn shared representations across heterogeneous cardiac conditions and improve generalization. Achieved 98.94% accuracy and 0.926 macro-F1 for arrhythmia classification, while MI detection achieved 99.70% accuracy, 99.02% macro-F1, and ROC-AUC of 0.9997, demonstrating strong discriminative performance across both tasks.
